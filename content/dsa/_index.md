# 📘 Data Structures & Algorithms (DSA)

Welcome to the **MiniLearn DSA Track**! This module covers asymptotic complexity, recursion, linear and non-linear data structures, graph algorithms, dynamic programming, and string pattern matching for technical interviews and competitive programming.

### 🗺️ Curriculum Modules

1. **[Basic Concepts](/dsa/basic-concepts/)**: Time & Space Complexity, Big-O / Big-Θ / Big-Ω notations, and Recursion & Backtracking.
2. **[Core Data Structures & Algorithms](/dsa/data-structures/)**:
   - **Arrays & Strings**: Prefix Sums, Sliding Window, Two Pointers, Palindromes, KMP & Z-Algorithm.
   - **Linked Lists, Stacks & Queues**: Singly/Doubly/Circular Lists, Fast & Slow Pointers, Monotonic Stacks, Deques, Priority Queues.
   - **Hashing & Heaps**: Hash Tables, Frequency Maps, Min/Max Heaps, Heap Sort.
   - **Trees & Tries**: Binary Trees, BST, AVL Trees, Segment Trees, Fenwick Trees (BIT), Prefix Tries.
   - **Graphs**: BFS, DFS, Topological Sort, Disjoint Set Union (DSU), Minimum Spanning Trees (Prim's & Kruskal's).
   - **Dynamic Programming & Paradigms**: Memoization, Tabulation, 1D/2D DP, Knapsack, Greedy, Divide & Conquer, Bit Manipulation, and Number Theory.
