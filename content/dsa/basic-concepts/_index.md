# 🧠 DSA Basic Concepts

Before diving into complex data structures, every software engineer must master three foundational pillars:

1. **[Time & Space Complexity](/dsa/basic-concepts/time-&-space-complexity/)**: Measuring how runtime and memory scale with input size `N`.
2. **[Asymptotic Notations (Big-O, Big-Θ, Big-Ω)](/dsa/basic-concepts/asymptotic-notations-big-o-big-θ-big-ω/)**: Formal mathematical upper, tight, and lower growth bounds.
3. **[Recursion & Backtracking](/dsa/basic-concepts/recursion-&-backtracking/)**: Solving self-similar subproblems and systematically exploring state-space trees.
