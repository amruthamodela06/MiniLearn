## 4-Week Structured DSA & Systems Mastery Plan

### Week 1: Arrays, Hashing, Two Pointers & Sliding Window
- **Day 1–2**: Two Sum, Group Anagrams, Top-K Frequent Elements, Product of Array Except Self, Longest Consecutive Sequence.
- **Day 3–4**: Valid Palindrome, 3Sum, Container With Most Water, Trapping Rain Water.
- **Day 5–7**: Best Time to Buy & Sell Stock, Longest Substring Without Repeating Characters, Minimum Window Substring, Sliding Window Maximum.

### Week 2: Stacks, Linked Lists, Binary Search & Trees
- **Day 8–9**: Valid Parentheses, Min Stack, Daily Temperatures (Monotonic Stack), Largest Rectangle in Histogram.
- **Day 10–11**: Reverse Linked List, Merge Two Sorted Lists, Linked List Cycle II, LRU Cache.
- **Day 12–14**: Binary Search in Rotated Sorted Array, Invert Binary Tree, Validate BST, Lowest Common Ancestor, Binary Tree Level Order Traversal.

### Week 3: Heaps, Tries, Backtracking & Graphs
- **Day 15–16**: Kth Largest Element, Find Median from Data Stream, Implement Prefix Trie, Word Search II.
- **Day 17–18**: Subsets, Combination Sum, Permutations, N-Queens.
- **Day 19–21**: Number of Islands, Clone Graph, Course Schedule (Topological Sort), Redundant Connection (Union-Find), Network Delay Time.

### Week 4: Dynamic Programming, Greedy & Bit Manipulation
- **Day 22–24**: Climbing Stairs, House Robber, Coin Change, Longest Increasing Subsequence, Word Break.
- **Day 25–27**: Unique Paths, Longest Common Subsequence, 0/1 Knapsack, Edit Distance.
- **Day 28–30**: Jump Game, Merge Intervals, Non-Overlapping Intervals, Single Number, Counting Bits.
