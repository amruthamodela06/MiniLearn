# 🐍 Python Programming Track

Master Python from foundational syntax and built-in data structures to Object-Oriented Programming, functional idioms, data science libraries, and web development.

### 🗺️ Curriculum Modules

1. **[Python Basics](/python/basics/)**: Syntax, Variables, Data Types, Operators, I/O, Conditionals, Loops, and Functions.
2. **[Data Structures](/python/data-structures/)**: Lists, Tuples, Sets, Dictionaries, `collections.deque`, and `numpy` arrays.
3. **[Object-Oriented Programming (OOP)](/python/oop/)**: Classes, Objects, Encapsulation, Inheritance, and Polymorphism.
4. **[Advanced Topics](/python/advanced-topics/)**: Decorators, Iterators & Generators, List Comprehensions, Lambdas, Exceptions, and File I/O.
5. **[Modules & Libraries](/python/modules-&-libraries/)**: Standard Library (`math`, `datetime`, `os`, `sys`), Regular Expressions (`re`), Data Science (`pandas`, `numpy`, `matplotlib`), and Web/GUI (`requests`, `flask`, `tkinter`).
