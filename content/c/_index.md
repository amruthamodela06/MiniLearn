# 🔧 C Programming Language Track

Understand how software interacts directly with hardware and memory through the **C Programming Language**.

### 🗺️ Curriculum Modules

1. **[C Basics](/c/basics/)**: Syntax, Data Types, Keywords, `printf`/`scanf` I/O, Operators, and Control Flow (`if`, `switch`, loops).
2. **[Functions](/c/functions/)**: Declarations, Prototype Definitions, `main` & `void`, Pass-by-Value vs Pass-by-Pointer, and Recursion.
3. **[Pointers](/c/pointers/)**: Memory Addresses, Pointer Arithmetic, Arrays & Pointers decay, and Function Pointers.
4. **[Memory Management](/c/memory-management/)**: Stack vs Heap layout, `malloc`, `calloc`, `realloc`, `free`, and preventing memory leaks.
5. **[Data Structures in C](/c/data-structures/)**: 1D/2D Arrays, NUL-terminated Strings, `struct` & `union`, and dynamic Linked Lists, Stacks, and Queues.
6. **[File Handling](/c/file-handling/)**: `FILE` streams, `fopen`, `fclose`, `fread`, `fwrite`, `fseek`, and text vs binary file persistence.
