# 💻 C++ & Standard Template Library (STL) Track

Bridge high-level abstraction with zero-overhead performance using modern **C++ (C++17/C++20)** and the **Standard Template Library (STL)**.

### 🗺️ Curriculum Modules

1. **[Everything in C](/cpp/everything-in-c/)**: How C++ builds upon C with references, function overloading, `constexpr`, and namespaces.
2. **[Object-Oriented Programming](/cpp/object-oriented-programming/)**: Classes, Constructors/Destructors (RAII), Encapsulation, Inheritance, Polymorphism, and Virtual Functions (`vtable`).
3. **[Standard Template Library (STL)](/cpp/stl-(standard-template-library)/)**: Sequence & Associative Containers (`vector`, `map`, `set`, `pair`), Container Adaptors (`stack`, `queue`, `priority_queue`), and Algorithms (`sort`, `binary_search`, `lower_bound`).
4. **[Advanced Modern C++](/cpp/advanced-topics/)**: Function & Class Templates, Smart Pointers (`std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`), Lambda Expressions, and Exception Handling.
