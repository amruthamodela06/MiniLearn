# ☕ Java Development Track

Build type-safe, concurrent, object-oriented applications with **Java** and the **Java Collections Framework**.

### 🗺️ Curriculum Modules

1. **[Java Basics](/java/basics/)**: JVM/JDK architecture, Primitive & Reference Types, Operators, Control Flow, Arrays, and immutable `String` vs `StringBuilder`.
2. **[OOP Concepts](/java/oop-concepts/)**: Classes & Objects, Encapsulation, Inheritance, Polymorphism, Abstract Classes, and Interfaces.
3. **[Java Collections Framework](/java/java-collections-framework/)**: `List`, `Set`, `Map` hierarchies, `ArrayList`, `HashMap` internals, `TreeMap`, `HashSet`, `Stack`, `Queue`, `ArrayDeque`, and `Comparable` vs `Comparator`.
4. **[Exception Handling](/java/exception-handling/)**: Checked vs Unchecked Exceptions, `try-catch-finally`, `try-with-resources`, `throw`, and `throws`.
5. **[File I/O](/java/file-i/o/)**: `File`, `Scanner`, `BufferedReader`, `FileWriter`, and `java.nio.file.Files`.
6. **[Multithreading](/java/multithreading/)**: Thread Lifecycle, `Thread` vs `Runnable`, `synchronized`, `volatile`, and Executor pools.
7. **[Java 8+ Modern Features](/java/java-8+-features/)**: Functional Interfaces, Lambda Expressions, Stream API (`map`, `filter`, `reduce`, `collect`), and `Optional<T>`.
